**Velvet Midnight** — a top-down heist game in three acts. You are the thief: sneak past patrolling guards and sweeping security cameras, pocket every painting, gold bar and jewel, then slip out the green exit before the alarm meter hits full. Guards patrol with vision cones that change colour with their suspicion, investigate noises, chase when they spot you, and search the room when they lose you. Cameras sweep their cones and fill the alarm fast — an EMP pulse knocks them dark. Coins lure guards away, lockpicks open shortcut doors, and shadow tiles hide you. Three hand-designed heists (museum, bank vault, casino penthouse), a ghost bonus for finishing quiet, and a time bonus for finishing fast.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — every file is served from `game/`.

**Controls:** WASD / arrows move · Shift sneak (slow, quiet, hard to spot in shadow) · X sprint (fast, loud) · Space or click throw a coin · E grab loot / pick a lock / slip out · Q EMP pulse · P pause · R restart · M mute · H help.
